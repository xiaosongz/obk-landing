Inline Ant Design outlined glyph (arrow-right by default); use as a suffix inside Button/TextLink or a prefix in Input.

```jsx
<Icon name="arrow-right" />
<Icon name="lock" size={26} style={{ color: "var(--bronze-500)" }} />
```

Names: arrow-right, arrow-left, lock, mail, search, environment, home, file-text. Never an icon without an adjacent label, except the arrow suffix.
