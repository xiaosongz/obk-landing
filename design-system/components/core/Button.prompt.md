Button in the five prototype treatments; pass `arrow` to add the → suffix that every Obelisk CTA carries.

```jsx
<Button variant="primary" size="lg" arrow href="#/portfolio">Explore our portfolio</Button>
<Button arrow>Investor portal</Button>
<Button variant="link" icon={<Icon name="file-text" />}>Subscription agreement</Button>
```

variant: primary (charcoal) · default (hairline) · bronze (single hero CTA) · inverse (on charcoal panels) · link. size md 40px / lg 48px. block for full-width.
